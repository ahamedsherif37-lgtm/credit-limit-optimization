# Credit Limit Optimization Using Risk-Based Models

## Project Overview

This project focuses on predicting credit card default risk using machine learning and using the predicted risk to support credit limit optimization.

## Objective

The main objective is to identify customers who are more likely to default and recommend suitable credit limits based on their risk level.

## Dataset

The project uses the UCI Credit Card Default dataset.

The dataset contains customer demographic information, credit information, bill amounts, payment amounts, payment history, and default status.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Project Steps

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Data Preprocessing
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Default Risk Prediction
9. Credit Limit Recommendation

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Model Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix

## Conclusion

The project demonstrates how machine learning can be used to predict credit default risk and support data-driven credit limit decisions.
